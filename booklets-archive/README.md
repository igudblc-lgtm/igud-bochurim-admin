# ארכיון חוברות לימוד

**עדכון ארכיטקטורה:** חוברות הלימוד (PDF כבדים, עד 33MB) כעת מקושרות ישירות מ-Google Drive שלכם ולא מועלות לאפליקציה — כך נשארים על תוכנית Firebase החינמית בלי צורך בכרטיס אשראי. התיקייה הזו עדיין שימושית כעותק מקומי מסודר של הקבצים בתוך הפרויקט (לגיבוי בלבד).

## מה לעשות עם חוברת שנשלחה היום לדפוס

1. **ודאו שהקובץ נמצא ב-Google Drive** שלכם (`igud.blc@gmail.com`) ומוגדר לשיתוף "כל מי שיש לו את הקישור יכול לצפות".
2. **העתיקו את קישור השיתוף** (לחצן "שיתוף" / "Share" ב-Drive → "העתק קישור").
3. **הדביקו אותו באפליקציה:** במסך **"מרכז חוברות ומודעות"**, ליד החוברת המתאימה, לחצו על **"🔗 קישור ל-Drive"**, הדביקו את הקישור ושמרו.
4. מרגע שקושר, אפשר לפתוח/להוריד את החוברת ישירות מהאפליקציה, והמערכת תנסה למזג אותה אוטומטית עם עמוד שער ושאלות מעודכנים לשנה הנוכחית (בכפוף למגבלות שיתוף של Google Drive לקבצים גדולים).
5. (אופציונלי, לגיבוי בלבד) אפשר גם לגרור את אותו קובץ לכאן, לתיקיית `booklets-archive`.

## מבנה קבצים מוצע (לא חובה)

ניתן, לנוחיותכם בלבד, לשמור כאן את הקבצים בפורמט:
```
booklets-archive/
  אלול.pdf
  תשרי.pdf
  חשון.pdf
  ...
```
