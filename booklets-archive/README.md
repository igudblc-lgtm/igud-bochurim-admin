# ארכיון חוברות לימוד

זו התיקייה לאחסון מאובטח ומסודר של קובצי חוברות הלימוד שהופקו בפועל (PDF/Word), בתוך הפרויקט עצמו.

## מה לעשות עם חוברת שנשלחה היום לדפוס

1. **גררו את הקובץ** (PDF או Word) לתוך התיקייה הזו — כך הוא שמור ומגובה בתוך הפרויקט (ונכנס גם לגיבוי הגיט, אם תתבצע הצלחה ל-Git/GitHub בעתיד).
2. **צרפו אותו גם בתוך האפליקציה:** במסך **"מרכז חוברות ומודעות"**, ליד החוברת המתאימה, לחצו על הכפתור **"תוכן קבוע (PDF)"**, ובחרו את אותו קובץ מתוך תיקיית `booklets-archive`.
3. מרגע שצורף, המערכת **"זוכרת"** את תוכן המאמר הקבוע הזה, ובכל שנה הבאה תדע לשלב אותו אוטומטית עם עמוד שער ולוח זמנים מעודכנים לשנה הנוכחית — ולהפיק קובץ PDF מאוחד ומוכן לדפוס בלחיצת כפתור, ישירות מתוך "תא הטייס השבועי".

## מבנה קבצים מוצע (לא חובה)

ניתן, לנוחיותכם בלבד, לשמור כאן את הקבצים בפורמט:
```
booklets-archive/
  אלול.pdf
  תשרי.pdf
  חשון.pdf
  ...
```
