# מערכת ניהול — איגוד בחורים

אפליקציית ווב (RTL, עברית מלאה) לניהול המודול "א חסידישע ליל שישי": לוח שנה שנתי, חוברות לימוד ומודעות, צ'ק-ליסט תפעולי וטופס סיכום ערב, ומעקב בחורים.

בנויה ללא build step — HTML/CSS/JS וניל. שמירת נתונים היברידית: מקומית ב-`localStorage` תמיד, ובנוסף סנכרון לענן (Firebase Firestore **בלבד** — ללא Storage, ללא עלות וללא צורך בכרטיס אשראי) ברגע שמוגדר חיבור (ראו "חיבור לענן" למטה). בפתיחה ראשונה המערכת נטענת עם נתוני דמו מלאים בעברית.

עיצוב מודרני עם מצב בהיר/כהה (כפתור בתפריט הצד, נשמר ב-localStorage). הפקות ההדפסה (חוברות, מודעות, דפי שער) תמיד נשארות בעיצוב בהיר, ללא קשר למצב התצוגה שנבחר באפליקציה.

## הרצה מקומית

```
npx serve .
```

או פתיחת `index.html` ישירות בדפדפן (העדיפו שרת מקומי, כדי שלא יהיו חסימות CORS בטעינת קבצי ה-JS).

## מבנה הקבצים

```
index.html          שלד האפליקציה — תפריט צד, בורר מסגרת, ראוטר מסכים
css/styles.css       מערכת העיצוב (כחול עמוק, זהב, לבן, אפור בהיר)
js/core.js           אתחול namespace גלובלי משותף
js/data.js           בנק נתוני דמו: פרשות, מאמרים, משפיעים, בחורים
js/store.js          שכבת state + persistence (localStorage + דחיפה לענן)
js/auth.js           ניהול תפקיד/הפעלה: מנהל מול רכז סניף, קודי גישה
js/cloud.js          עטיפת Firebase (Firestore בלבד), נופלת בחזרה ל-localStorage אם לא מוגדר
js/firebase-config.js  כאן מדביקים את firebaseConfig מה-Firebase Console
js/utils.js          פונקציות עזר (תגיות סטטוס/סוג, תאריך עברי, DOM helpers, ICS, JSON)
js/dashboard.js       מסך "תא הטייס השבועי"
js/roadmap.js         מסך "מפת דרכים שנתית" (עריכה למנהל בלבד)
js/printmedia.js       מסך "מרכז חוברות ומודעות", חיפוש, הדפסה
js/operator.js         מסך "אחראי ליל שישי" — מוגבל לנתוני הסניף המחובר
js/students.js         מסך "מצב הבחורים" — מוגבל לנתוני הסניף המחובר
js/admin.js            מסך "ניהול מערכת": סניפים/קודים, גיבוי-שחזור, סנכרון לענן, איפוס מוגן
js/pdfmerge.js          מיזוג PDF: עמוד שער+שאלות דינמי (html2canvas) + תוכן המאמר הקבוע (pdf-lib)
js/main.js             ראוטר, מודאלים, התחברות, אתחול כללי
booklets-archive/       אחסון מקומי של קובצי חוברות אמיתיים (PDF/Word) שהופקו בפועל
```

## מסגרות נוספות

בורר "מסגרת מוצגת" בראש התפריט מוכן מראש לקליטת מסגרות נוספות של האיגוד מעבר ל"א חסידישע ליל שישי" (כרגע מוצגת כפריט מנוטרל "בקרוב").

## סניפים וקודי גישה

מסך "ניהול מערכת" (גלוי למנהל בלבד) מאפשר יצירת סניפים נוספים, כל אחד עם קוד גישה בן 4 ספרות. קוד המנהל הראשי (ברירת מחדל: `770`, נשמר ב-state.security.adminCode) פותח גישה מלאה; קוד סניף פותח גישה מוגבלת לנתוני הסניף שלו בלבד במסכי "אחראי ליל שישי" ו"מצב הבחורים". המשתמש מחליף תפקיד דרך כפתור "החלפת משתמש / קוד גישה" בתפריט הצד.

## חיבור לענן (Firebase Spark — חינמי, Firestore בלבד)

עריכת `js/firebase-config.js` עם ה-`firebaseConfig` מהפרויקט מפעילה סנכרון Firestore בזמן אמת בין מכשירים. **אין צורך ב-Firebase Storage ואין צורך בכרטיס אשראי** — תוכנית Spark החינמית מספיקה לגמרי, כי:
- קבצי PDF כבדים (חוברות לימוד) **לא** מועלים לאפליקציה כלל — הם מקושרים ישירות מ-Google Drive (ראו "חוברות" למטה).
- תמונות קטנות שמצורפות למודעות נדחסות אוטומטית בצד הלקוח (canvas, ~150KB WebP/JPEG) ונשמרות כ-Data URL קטן בתוך מסמך ה-Firestore עצמו.

כל עוד `js/firebase-config.js` ריק (`null`), האפליקציה ממשיכה לעבוד מקומית בלי שגיאות. לאחר החיבור, כפתור "סנכרן נתונים מקומיים לענן" במסך "ניהול מערכת" מעלה את הנתונים הקיימים ל-Firestore בלחיצה אחת.

## גיבוי, שחזור ואיפוס

מסך "ניהול מערכת" כולל ייצוא גיבוי מלא ל-JSON, שחזור מקובץ גיבוי, וכפתור "איפוס נתוני דמו" המוגן בקוד מנהל לפני כל מחיקה.

## חוברות — קישור ל-Google Drive + שער דינמי, גלגול שנתי אוטומטי

כל חוברת חודשית מורכבת משני חלקים:
- **קובץ המאמר (PDF כבד, עד 33MB):** נשאר ב-Google Drive שלכם ואינו מועלה לאפליקציה כלל. מקשרים אותו דרך הכפתור **"🔗 קישור ל-Drive"** ליד כל חוברת במסך "מרכז חוברות ומודעות" — מדביקים קישור שיתוף רגיל, והמערכת מזהה את מזהה הקובץ אוטומטית.
- **עטיפה דינמית:** החודש העברי, הפרשות, לוח הזמנים ושאלות העיון — נשלפים אוטומטית מנתוני השנה הנוכחית.

בלחיצה על "תצוגה מקדימה" (או מכרטיס ההתראה בתא הטייס) המערכת יוצרת עמוד שער+שאלות מעודכן (באמצעות html2canvas, כדי לשמר עברית מושלמת) ומנסה למזג אותו עם קובץ ה-PDF מה-Drive (באמצעות pdf-lib) לקובץ אחד מוכן לדפוס. **מגבלה חשובה:** עבור קבצים גדולים (מעל ~25MB בד"כ) או כאלה שאינם משותפים כ"כל מי שיש לו קישור", Google Drive חוסם הורדה ישירה ("לא ניתן לסרוק את הקובץ לאיתור וירוסים") — במקרה כזה המערכת מזהה זאת אוטומטית ונופלת בחזרה למתן עמוד השער/שאלות בנפרד, לצד פתיחת הקובץ המקורי ב-Drive בלשונית נפרדת.

**7 ימים לפני כל ראש חודש**, אם קושרה חוברת Drive לחודש הבא, מופיעה בתא הטייס השבועי כרטיסיית "✅ מוכן לאישור דפוס" עם 3 פעולות: תצוגה מקדימה ועריכת שאלות, אישור והורדה (מאוחד או נפרד, לפי המגבלה שלעיל), ושליחת הזמנה מוכנה לבית הדפוס הכוללת גם קישור ישיר לקובץ ב-Drive (לפי הגדרות ב"ניהול מערכת" → "הגדרות דפוס").
