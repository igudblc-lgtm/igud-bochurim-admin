# מערכת ניהול — איגוד בחורים

אפליקציית ווב (RTL, עברית מלאה) לניהול המודול "א חסידישע ליל שישי": לוח שנה שנתי, חוברות לימוד ומודעות, צ'ק-ליסט תפעולי וטופס סיכום ערב, ומעקב בחורים.

בנויה ללא build step — HTML/CSS/JS וניל. שמירת נתונים היברידית: מקומית ב-`localStorage` תמיד, ובנוסף סנכרון לענן (Firebase Firestore + Storage) ברגע שמוגדר חיבור (ראו "חיבור לענן" למטה). בפתיחה ראשונה המערכת נטענת עם נתוני דמו מלאים בעברית.

עיצוב מודרני עם מצב בהיר/כהה (כפתור בתפריט הצד, נשמר ב-localStorage). הפקות ההדפסה (חוברות, מודעות, דפי שער) תמיד נשארות בעיצוב בהיר, ללא קשר למצב התצוגה שנבחר באפליקציה.

## הרצה מקומית

```
npx serve .
```

או פתיחת `index.html` ישירות בדפדפן (העדיפו שרת מקומי, כדי שלא יהיו חסימות CORS בטעינת קבצי ה-JS).

## מבנה הקבצים

```
index.html          שלד האפליקציה — תפריט צד, בורר מסגרת, ראוטר מסכים
css/styles.css       מערכת העיצוב (כחול עמוק, זהב, לבן, אפור בהיר)
js/core.js           אתחול namespace גלובלי משותף
js/data.js           בנק נתוני דמו: פרשות, מאמרים, משפיעים, בחורים
js/store.js          שכבת state + persistence (localStorage + דחיפה לענן)
js/auth.js           ניהול תפקיד/הפעלה: מנהל מול רכז סניף, קודי גישה
js/cloud.js          עטיפת Firebase (Firestore + Storage), נופלת בחזרה ל-localStorage אם לא מוגדר
js/firebase-config.js  כאן מדביקים את firebaseConfig מה-Firebase Console
js/utils.js          פונקציות עזר (תגיות סטטוס/סוג, תאריך עברי, DOM helpers, ICS, JSON)
js/dashboard.js       מסך "תא הטייס השבועי"
js/roadmap.js         מסך "מפת דרכים שנתית" (עריכה למנהל בלבד)
js/printmedia.js       מסך "מרכז חוברות ומודעות", חיפוש, הדפסה
js/operator.js         מסך "אחראי ליל שישי" — מוגבל לנתוני הסניף המחובר
js/students.js         מסך "מצב הבחורים" — מוגבל לנתוני הסניף המחובר
js/admin.js            מסך "ניהול מערכת": סניפים/קודים, גיבוי-שחזור, סנכרון לענן, איפוס מוגן
js/pdfmerge.js          מיזוג PDF: עמוד שער+שאלות דינמי (html2canvas) + תוכן המאמר הקבוע (pdf-lib)
js/main.js             ראוטר, מודאלים, התחברות, אתחול כללי
booklets-archive/       אחסון מקומי של קובצי חוברות אמיתיים (PDF/Word) שהופקו בפועל
```

## מסגרות נוספות

בורר "מסגרת מוצגת" בראש התפריט מוכן מראש לקליטת מסגרות נוספות של האיגוד מעבר ל"א חסידישע ליל שישי" (כרגע מוצגת כפריט מנוטרל "בקרוב").

## סניפים וקודי גישה

מסך "ניהול מערכת" (גלוי למנהל בלבד) מאפשר יצירת סניפים נוספים, כל אחד עם קוד גישה בן 4 ספרות. קוד המנהל הראשי (ברירת מחדל: `770`, נשמר ב-state.security.adminCode) פותח גישה מלאה; קוד סניף פותח גישה מוגבלת לנתוני הסניף שלו בלבד במסכי "אחראי ליל שישי" ו"מצב הבחורים". המשתמש מחליף תפקיד דרך כפתור "החלפת משתמש / קוד גישה" בתפריט הצד.

## חיבור לענן (Firebase)

עריכת `js/firebase-config.js` עם ה-`firebaseConfig` מהפרויקט מפעילה סנכרון Firestore בזמן אמת בין מכשירים, ואחסון קבצים (חוברות) ב-Firebase Storage. כל עוד הקובץ ריק (`null`), האפליקציה ממשיכה לעבוד מקומית בלי שגיאות. לאחר החיבור, כפתור "סנכרן נתונים מקומיים לענן" במסך "ניהול מערכת" מעלה את הנתונים הקיימים לענן בלחיצה אחת.

## גיבוי, שחזור ואיפוס

מסך "ניהול מערכת" כולל ייצוא גיבוי מלא ל-JSON, שחזור מקובץ גיבוי, וכפתור "איפוס נתוני דמו" המוגן בקוד מנהל לפני כל מחיקה.

## חוברות — ארכיטקטורה מודולרית (שער דינמי + תוכן קבוע) וגלגול שנתי אוטומטי

כל חוברת חודשית מורכבת משני חלקים:
- **תוכן קבוע (`corePdfFile`):** עמודי ה-PDF הנצחיים של המאמר עצמו. מצורפים פעם אחת דרך כפתור "תוכן קבוע" ליד כל חוברת במסך "מרכז חוברות ומודעות".
- **עטיפה דינמית:** החודש העברי, הפרשות, לוח הזמנים ושאלות העיון — נשלפים אוטומטית מנתוני השנה הנוכחית.

בלחיצה על "תצוגה מקדימה של הקובץ המאוחד" (או מכרטיס ההתראה בתא הטייס) המערכת יוצרת עמוד שער+שאלות מעודכן (באמצעות html2canvas, כדי לשמר עברית מושלמת) וממזגת אותו עם ה-PDF הקבוע (באמצעות pdf-lib) לקובץ PDF אחד מוכן לדפוס.

**7 ימים לפני כל ראש חודש**, אם קיים תוכן קבוע לחוברת החודש הבא, מופיעה בתא הטייס השבועי כרטיסיית "✅ מוכן לאישור דפוס" עם 3 פעולות: תצוגה מקדימה ועריכת שאלות, אישור והורדת הקובץ המאוחד, ושליחת הזמנה מוכנה לבית הדפוס (לפי הגדרות ב"ניהול מערכת" → "הגדרות דפוס").
